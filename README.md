# PBU31 — Proposta Branca Universal | Lovi

Site institucional de movimento cívico em formação. **PMI não é apresentado como partido político registrado; Lovi não tem candidatura anunciada.**

Pautas: paz, diálogo, respeito às diferenças, ciência, tecnologia, economia, preservação ambiental, dignidade humana e análises documentadas de propostas públicas.

Site estático: `index.html`, `participar.html`. O convite para participar não corresponde a filiação partidária formal. Nenhum dado de formulário será armazenado sem backend seguro e consentimento.

Hospedagem: GitHub Pages ou Web Hosting Business Hostinger, quando configurados.

## Identidade atual
PBU31 significa **Proposta Branca Universal**; trata-se de uma comunidade de discussão cívica e estudo de reformas institucionais, sem registro partidário, candidatura anunciada ou filiação. Eventual formação futura de partido dependerá de decisão posterior e exigências legais.
